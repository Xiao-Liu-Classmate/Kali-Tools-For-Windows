Kali-Tools-For-Windows 工具清单
=====================================

工具编号	工具名	用途	部署方式
1	Nmap	端口扫描器	下载 exe 静默安装
2	Masscan	高速端口扫描器	下载 zip 二进制解压
3	Sqlmap	SQL 注入检测利用工具	Git 克隆源码，依赖 Python
4	Hydra	多协议暴力破解工具	下载 zipWindows 二进制包
5	Hashcat	哈希密码破解工具	下载 7z 二进制包
6	FFUF	Web 模糊测试、目录爆破	Git 克隆源码
7	Dirsearch	Web 网站目录扫描工具	Git 克隆源码，依赖 Python
8	CrackMapExec	内网 SMB / 域渗透工具	Git 克隆源码，pip 本地安装，依赖 Python
9	Whois	域名信息查询工具	微软 Sysinternals 工具包解压
10	Xray	Web 漏洞扫描器（闭源）	仅创建空文件夹，提示用户手动下载二进制
