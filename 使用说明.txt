Kali Tools For Windows v1.1 使用说明
=====================================

[简介]
将 Kali Linux 常用安全工具一键部署到 Windows 系统。

[使用方法]
方式一（推荐）：右键 "启动部署工具.bat"，选择"以管理员身份运行"
  - 图形界面 dist\KaliToolsGUI.exe 存在时自动启动 GUI（支持勾选工具、一键部署/卸载）
  - 不存在时自动回退到 PowerShell 部署脚本 Kali-Tools-Deployer.ps1
方式二：右键 "SecTools_Deploy.bat"，选择"以管理员身份运行"
  - 输入工具编号（逗号分隔，如 1,3,7）或输入 A 全部部署
  - 等待工具安装完成
工具统一安装到 C:\SecTools 目录

[部署目录]
  工具安装目录：C:\SecTools\
  日志文件：C:\SecTools\deploy_log.txt

[图形化界面]
  运行 dist\KaliToolsGUI.exe 可通过图形界面选择部署工具
  支持一键部署、卸载、查看日志、SHA256 校验等功能

[常见问题]

Q: 提示不是管理员权限？
A: 右键 bat 文件，选择"以管理员身份运行"

Q: 下载很慢或失败？
A: 1. 挂代理后再试
   2. 使用 gh-proxy.com 代理 GitHub 下载
   3. 手动下载后放入 C:\SecTools 对应目录

Q: 工具无法运行？
A: 部分工具需要 Python 环境，请确保已安装 Python 3

Q: 安全软件报毒？
A: 安全工具可能被误报，建议添加信任
